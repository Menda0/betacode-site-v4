Manter o runtime Node.js usado no desenvolvimento do projeto atualizado com correções de segurança.

Eliminar a exposição do ambiente de desenvolvimento às vulnerabilidades corrigidas nas versões de segurança do Node.js de outubro de 2026.

## Critérios de aceitação

- O projeto declara uma versão mínima do Node.js que contém as correções.
- O ambiente local usa uma versão corrigida.
