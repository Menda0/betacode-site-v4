# S-004: Delete blog posts

## User story

As an admin, I want to delete blog posts so that outdated or incorrect Insights content can be removed.

## Acceptance criteria

- [ ] Admin can delete a post from the dashboard with an explicit confirmation step
- [ ] Deleted posts no longer appear in the admin list
- [ ] Deleted posts are no longer returned by the public blog content layer
- [ ] Only authenticated admins can delete posts
