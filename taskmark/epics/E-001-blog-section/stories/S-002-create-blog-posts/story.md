# S-002: Create blog posts

## User story

As an admin, I want to add new blog posts from the dashboard so that new Insights content can be published without editing code.

## Acceptance criteria

- [ ] Admin can create a blog post with required fields (slug, title, excerpt, publishedAt, author, category, reading time, content, locale)
- [ ] Created posts appear in the admin list
- [ ] Invalid payloads are rejected with clear validation errors
- [ ] Only authenticated admins can create posts
