# E-001: Blog section

## Goal

Create a blog section admin dashboard that feeds the existing public blog section on the site.

## Scope

- Admin dashboard to list, create, edit, and delete blog posts
- Wire admin-managed content into the current Insights / blog section UI

## Out of scope

- Redesigning the public blog section presentation (unless required to consume admin data)
- Unrelated site admin features

## Success metrics

- Editors can list, add, update, and delete blog posts from an admin dashboard
- The existing public Insights section displays content sourced from that dashboard
